# User guide

This guide helps you work with GAMS in Visual Studio Code. It is written for modelers who are new to VS Code. You do not need to know GAMS Studio.

This extension is unofficial. It is not made or supported by GAMS Development Corp.

## Pages

1. [Getting started](01-getting-started.md): install, set up GAMS, run your first model.
2. [Editing GAMS code](02-editing.md): highlighting, completion, outline, definitions, help, comments.
3. [Running models](03-running.md): run, compile, log, errors, main files, projects, tasks.
4. [Debugging and profiling](04-debugging-profiling.md): breakpoints, variables, timing per statement.
5. [GDX files](05-gdx.md): viewer, filters, charts, compare, export, search.
6. [Option files and model library](06-option-files-model-library.md): solver options, library models.
7. [GAMS Connect and NEOS](07-connect-neos.md): Connect files, running on the NEOS Server.
8. [Settings and keys](08-settings-and-keys.md): every setting and every shortcut.

## Words used in this guide

- **Command Palette**: press `Ctrl+Shift+P` (macOS: `Cmd+Shift+P`), type a few letters, press Enter. All GAMS commands start with "GAMS:".
- **Settings**: press `Ctrl+,` and search for "gams".
- **Problems panel**: press `Ctrl+Shift+M`. It lists errors with file and line.
- **Sysdir**: the GAMS system directory. This is the folder that contains the `gams` program.
- **(extra)**: a feature this extension adds. GAMS Studio does not have it.
